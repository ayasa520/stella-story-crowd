# Native speed-mode static evidence archive

This package preserves four bounded trace/Capstone pairs, the original report,
menu inventory and inspection limits. It installs no speed configuration and
does not establish the active Unity timeScale in any recording.

Both extracted ON and OFF groups contain `×5.0`; the numeral alone does not
prove enabled speed mode. Per-recording appearance, active state, command onset,
frame deltas and Animator-local speed remain separate evidence requirements.
The custom ADVPlayer/View object inspection errors are retained without claiming
that unread serialized values were recovered.

Original local R references and all copied receipt bytes are preserved. Use
MANIFEST.json to map copied source paths; referenced sprites, APK/native binaries
and source video remain local and are not duplicated here.
