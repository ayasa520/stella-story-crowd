## Source and render contract

The actual canonical PairingViewer applies renderPose at beforeModelUpdate. The
shipped cubism4 SDK then calls Core.update and loadParameters in that order. The
instrument reads applied parameter/part arrays immediately before the real Core
update and pairs the latest same-instance sample with a real renderer return.
It calls the original update/render exactly once and does not write parameters,
call seek/renderPose/render manually, replace the clock, or change preview rate.
The factory wrapper returns the original Promise/result. A detached observation
branch swallows diagnostic errors into partial evidence. Original factory/Core/
renderer exceptions are recorded and propagated unchanged; diagnostic failures
cannot reject production model loading or replace an original exception.

Each character case makes one synchronous capture point after its actual actor
renderer: one raw WebGL RGBA read and the same canvas's PNG. Record sourceURL,
instance, render, game frame, lastApplied sequence/values, transforms and bounds.
The offline index compares PNG-decoded RGBA with the framebuffer after row reversal
only; a mismatch remains explicit and is never corrected by recoloring or fitting.
The stage PNG is not reconstructed from the texture atlas.

An asynchronous page screenshot cannot prove the same renderer frame. At most
eight short-window compositor JPEG candidates are retained for each static
capture. A readable parent HUD updates on every actual render. Only an exact
render/gameFrame/instance/lastApplied tuple read from a candidate can bind it to
the actor capture. A missed tuple leaves whole-stage same-frame pending. Do not
pause, draw a second time, repeat the actor read, or rerun the case. The BG case
uses three bounded windows for7/8/9 and no actor readback. Character cases have one
window each; maximum retained compositor candidates are72 overall.

Use parent1280×1000 and the established QA iframe outer preset480×856 before
advancing to any target. Change only those two outer iframe dimensions. Keep game
CSS/body/camera untouched. Measure the actual 9:16 viewport, iframe borders,
actor intrinsic/CSS size and PIXI renderer.screen/resolution; actual heights may
be853/854/856. No image is called480×856 merely because its outer iframe is856.
HUD occupies only a measured empty parent side margin and never the game image.

## Resource and compilation gate

Each character case binds exactly four original identity responses: detail,
model JSON, MOC and the single texture. Before Chrome, compare served bytes with
local frozen bytes. Inside Chrome, read only these response bodies, require
Accept-Encoding identity, absent/identity Content-Encoding, HTTP200, exact declared
Content-Length, exact actual SHA, at most8MiB per response and16MiB total per case.
Reject duplicate identity responses and service-worker responses. BG additionally
binds its one original plate response. Unrelated response bodies are not read.
The runner has an absolute75-second case deadline,540-second overall deadline
and20-second bounded partial-evidence cleanup. Page creation, settings, navigation
and identity/body waits are inside the cleanup scope. A late-created Page is
closed. Response headers/declared length are checked before body access; actual
decoded length has a separate byte budget. These controls are static drafts,
not a runtime success claim. A driver/renderer failure still requires the owner
to close immediately and report any nonzero process receipt.

Compile with the canonical Site compiler for each exact scene/start. Do not cache
the baseline by scene alone. All top-level properties, original source fields,
all5599 nodes and all edges are compared; character candidates may change only
model. List every changed node, including inherited consequences such as
Reinhard8. ROOT must explicitly approve that full list. Do not truncate the diff
to the authored target. The BG case uses the unchanged formal program and no
memory preview. Natural edges are checked in both raw/review data and compiled
programs. The final root compiler receipt must supply each program SHA and exact
approvedCompiledDifferences; draft placeholders are not executable.

   No waiting for ROOT or image review with Chrome open. No automatic restart
