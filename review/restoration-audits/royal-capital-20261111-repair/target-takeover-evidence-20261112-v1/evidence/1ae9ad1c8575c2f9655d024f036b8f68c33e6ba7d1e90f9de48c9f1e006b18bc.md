# Isolated ARM host tools for deferred Stella production comparisons

This directory prepares dependencies only. It does not authorize a browser,
adapter, production compilation, registry scope, preview or restoration claim.
The desktop `node_modules` trees, system installations and existing ARM Python
environment remain untouched.

`tsx` 4.22.1, `esbuild` 0.28.0 and `@esbuild/linux-arm64` 0.28.0 are pinned from
the canonical Site lockfile. The explicit ARM optional package supplies the
native esbuild binary without running its install lifecycle. Every npm install
uses `--ignore-scripts`; browser download is disabled in the command environment.

The Playwright CLI version and integrity are pinned from exact registry metadata
only after the local/cold metadata and npm-cache lookup. Registry metadata,
source lock bindings, command timeouts, bounded-process results, local lock and
installed architecture are retained as evidence. Version/help checks do not
constitute a browser session or production execution.

Preparation is complete: Node 26.13.0, tsx 4.22.1, esbuild 0.28.0 and
`@playwright/cli` 0.1.24 passed version checks; CLI help also passed. This CLI
pins `playwright` and `playwright-core` to `1.66.0-alpha-1794252756000`, matching
the saved exact registry metadata. No alternate browser was downloaded.

Use the absolute entry paths in `toolchain-receipt.json` after the root's
separate review and release. The installed esbuild ELF is AArch64. All 252
regular package files equal their six npm tarballs, whose SHA-512 SRIs match
the local lock. The source lock pins and eight selected existing-environment
file guards are unchanged. Final `/proc` inspection found zero active browser
cores and zero Playwright CLI/daemon processes.
