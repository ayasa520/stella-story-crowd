- `native/scenes/<scene_id>.json`：游戏原生静态剧情内容，直接使用 `scenario_list`、`video_list`、`branch_work_list`、`chartmap`。不包含 Studio 节点外壳或玩家账户数据。

- `manifest.json`：当前有正文场景的来源、审核和结构就绪状态，以及完整目录与手工连线。
